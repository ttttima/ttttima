### 📘 Git Cheat Sheet

| Task | Command |
| :--- | :--- |
| Set your name (once per computer) | `git config --global user.name "Jan Kowalski"` |
| Set your email (once per computer) | `git config --global user.email "jan@example.com"` |
| Check configuration | `git config --global --list` |
| Check repository status | `git status` |
| Download changes | `git pull` |
| Upload changes | `git add .` → `git commit -m "Message"` → `git push` |
| Create a new branch | `git switch -c feature-name` |
| Switch branch | `git switch main` |
| View commit history | `git log --oneline` |
| Check remote repository | `git remote -v` |

**First project upload**

```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/USER/REPO.git
git push -u origin main
```
